# 全等级自动接入回放（0.1.63-dev）

56 个可玩种族／职业组合全部通过；共 3304 个 1—59 级独立接入快照、336 次任务接续、56 次满级退出检查。原始结果与输入 SHA256 见 [LEVEL_ENTRY_REPLAY.json](LEVEL_ENTRY_REPLAY.json)。

本报告验证任意等级接入的固定场景，不作为连续 1—60 升级路线已经贯通的证明。

## 修复

TaskChoices 原先只要同一状态中有一项未知经验，就取消整个状态组的经验比较。例如联盟人类战士 26 级赤脊山快照推荐 #125（90 经验），同组却有移动收益更高的 #34（1950 经验）。35 级荆棘谷快照则被全部落在区域中心、经验未知的 #97331 排到首位。

现在保持资格、手动指定、受阻、低价值、当前实例和接取状态优先级；同组且均有移动时间的候选先比较已知收益，按经验／完整移动时间排序，再按移动时间保留未知收益候选。不删除未知任务，不填造经验，不改变区域参考点。已接任务的整批移动优化继续包含所有有效成员。

人类战士 59 个固定接入快照中 24 个首选发生变化；26 级首选 #34，35 级首选 #204（2700 经验）。这些是固定状态结果，不是实际练级效率提升比例。

## 覆盖与复现

运行：`python3 tools/check_level_entry.py`。

- 使用固定 QuestieDB 1.0.12 Forever 实际 API 与修正，角色组合来自官方可玩表和 70862 CharBaseInfo 的一致结果。
- 地图可读范围受本构建 UiMapAssignment 限制，仅用完整区域矩形，在相同 MapID 下计算世界坐标直线距离；跨世界不捏造距离。客户端地图接口及 HBD 实际运行仍待实机验证。
- 每级使用独立空历史、空任务日志；跑速 7 码／秒，无已知航线／炉石、无专业／声望解锁。1—10 级用种族起始任务位置，之后使用报告所列区域中心。并未覆盖所有位置或历史组合。
- 每组合在 10、20、30、40、50、59 级自动选择任务，模拟接取、目标状态、到达、可交付、交付后再推荐。全程无手动锁定；到达不改变完成状态。等级保持固定，目标／交付事件由夹具提供。
- 59 级以内首选覆盖 41 个不同任务；100 个天裔起始快照仍使用未知经验候选，证明未知数据未被排除。60 级正确返回练级完成状态。
- 402 项回归、Lua5.1 语法、开发内容结构检查与构建通过。新增回归在旧排序下失败，覆盖输入顺序变化、多个未知候选、仅未知任务、手动选择与已接任务优先。
