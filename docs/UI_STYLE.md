# AILeveling 界面规范

本文件是已有界面的统一规范。运行时颜色、字号和公共尺寸集中在 `UI/Main.lua`；各页面复用 `Text`、`Button`、`Rounded`。修改样式时先调整规范与公共值，再更新相关页面。

## 1. 整体风格

参照 Horizon Focus。地点居首，标题下的细线带一小段金色。当前任务使用金色栏目名和蓝色竖线，子目标缩进一层，数量右对齐。副本概览显示实际任务数，各组独立编号。普通练级保留当前、接下来、顺路和折叠的其他已接任务。主面板和导航共用同一套正文、地点和状态色。

任务栏标题与正文共用一层可调底色。「设置 → 界面显示 → 全局背景透明度」统一调整任务栏、导航与附近提示、详情侧栏及各窗口。新配置默认 60%。旧配置数值不一致时显示「沿用各面板设置」，首次调整后统一。悬停与选中底色为 60% 透明。背景与文字、图标分别绘制。列表行使用透明底，悬停才提亮。选中行使用浅色底和左侧金线，文字仍保留状态色。

### DaylightUI 联动皮肤

启用 DaylightUI（公开 API 1.x）时，使用其 `Skin/Text/Button/Close/Input/Switch/Menu/Bar` 绘制窗口、按钮、关闭、输入、开关、菜单和进度条。详情使用窗口样式，附近提示使用任务追踪面板样式。主任务栏和中央导航在两套皮肤中均使用无外框、无阴影的平面底色。各面板的背景透明度由 AILeveling 设置控制。

任务栏沿用当前皮肤的中文字体，按下表确定字号。DaylightUI 的字体倍率和 AILeveling 的字号设置共同作用于文字与布局。

两套皮肤使用 AILeveling 的任务状态色。DaylightUI 继续提供字体、字形、控件和导航箭头的强调色。物品链接保留品质色。

`Login` 与 `StyleChanged` 通知统一刷新字体、窗口和内容。只调用安装中的公开接口，不复制 DaylightUI 代码或素材，不新增轮询或皮肤配置。未启用 DaylightUI 时，下述原有配色和字号规范继续生效。

## 2. 颜色语义

| 用途 | 颜色 | 规则 |
| --- | --- | --- |
| 正文、地点、页面标题 | 近白 `#F7F8FD` | 一级阅读信息 |
| 区域、说明、经验与路程标签 | 灰蓝 `#C3CADD` | 次要信息，保持可辨识 |
| 导航中的地名、站点、入口 | 浅蓝 `#96CCFF` | 两套皮肤共用。仅突出地点名称，动作词沿用当前行文字色。当前步骤、下一步和展开的行程使用同一规则 |
| 当前追踪栏目、待接任务、未完成计数 | 金色 `#F5C76E` | 当前动作配金色竖线 |
| 地点、NPC 链接、任务链接、跑路入口 | 浅蓝 `#96CCFF` | 同时配行动图标／文字；普通接取说明使用灰蓝 |
| 可交付、完成勾选、装备提升数值 | 绿色 `#85E8A6` | 已接取任务不得使用此色 |
| 副本内进行中的任务 | 淡紫 `#CFA6FF` | 物品子目标使用束口袋图标 |
| 暂缓、不可用 | 灰蓝 | 完成的子目标用绿勾和绿色数量 |
| 错误或负向属性 | 浅红 `#F29C9C` | 仅用于实际错误、负值 |
| 导航箭头与距离 | 职业色 | 不覆盖任务状态色 |

状态同时使用图标和文字／进度，颜色不单独承担区分作用。背景、边线、悬停及选中颜色均从公共色表读取；页面不得再自设另一套色表。原生物品／技能链接的颜色保留。

## 3. 字号与对齐

任务栏参照 Polestar 行程图对应版本的[字号表](https://github.com/fitzforge/polestar/blob/0d937f12f47913487c5fc6616237e31e8ca46ede/addon/Polestar/Theme/Theme.lua)和[步骤行](https://github.com/fitzforge/polestar/blob/0d937f12f47913487c5fc6616237e31e8ca46ede/addon/Polestar/UI/JourneyPanel.lua)。以下为标准倍率下的游戏界面单位。

| 位置 | 基础字号 |
| --- | --- |
| 当前 NPC、地点名 | 15 |
| 当前行动及任务名 | 14 |
| 任务目标正文 | 13 |
| 行程步骤、耗时、顶栏计数、下一项任务 | 12 |
| 区域、说明、章节名、等候与乘坐时间 | 11 |

文字使用轻阴影。任务栏左右留 14，区域与行动说明对齐到标题文字列。章节栏高 28，工具栏高 34。行程标题高 30，目的地行至少 22，单行步骤高 24，时间列宽 56、右对齐。长步骤和换乘说明按实际文字高度扩展。上述尺寸跟随字号同比缩放。详情面板沿用其独立字号。

中央导航背景透明度由 AILeveling 统一控制，两套皮肤均跟随全局背景透明度。接取、执行和交付指引与可点击的 NPC 头像行共用无边框底色和宽度。标准字号下，两侧留白 14，指引与 NPC 名称从左侧 39 处起排。行动标题、NPC 名和说明分别使用 14、13 和 12 号字，随字号设置一同缩放。只对背景应用这个值，正文与行动图标保持清晰。「导航箭头与距离不透明度」调节箭头及右侧读数。当前行动与行动图标左对齐，距离和步序用辅助字号靠右。具体指引在行动正下方。下一步和 NPC 列表各用一条内缩细线与上一段分开。步骤条按实际文字高度收拢，WaypointUI 接管方向后保留两行指引。

## 4. 间距与控件

- 使用 4 px 的间距基准：紧邻信息 4、行间 8、面板内边距 12、区段间距 16、子目标缩进 24 px。文字相关的间距跟随字号缩放。
- 主要图标 16 px，小图标 12 px；图标与文字留 8 px。原生勾选符号保留独立列。
- 面板圆角 6 px，按钮圆角 4 px。副本名下的金色细线延伸至内容右缘。副本任务用彩色标题和留白分组，常规任务栏使用 1 px 淡色分隔线。
- 普通按钮高 28 px；图标操作区至少 24 px，使用中性悬停底。相邻按钮间隔 8 px。
- 常规引导的地点与区域分行，区域位于地名下方 3 px。收起时在可用空间内同排展示。
- “接下来”沿用二级分组样式，同排用状态色显示当前接取状态；下方复用任务行，展示等级、任务名、内缩目标图标与数量，以及目的地。标题与目标间隔 4 px；整组距上方分隔线 8 px，距下方“后续行程”16 px，均随字号缩放。计划交付但当前尚未完成时写“完成后交付”，状态仍按任务日志显示。
- 只在实际滚动内容中预留 16 px 原生滚动条空间；其他区域使用完整内容宽度。
- HUD 可用鼠标调整宽高。贴靠小地图时，高度最多占用小地图下方的可见空间。空间紧张时，地点和当前任务名固定在上方，职业提醒、副本建议和任务明细可在下方滚动查看。

图标视距修正和原生控件锚点允许保留必要的局部尺寸；文字使用公共字号角色，不另设局部字号。

## 5. 信息结构与交互

HUD 使用单列。首行横排地点、区域、菜单和收起按钮，宽度充足时用亮白色正文字号显示任务数。菜单和收起按钮使用亮白符号，鼠标悬停时显示淡色高亮。两个按钮平时直接显示在任务栏底色上。紧接着显示当前任务名、等级、状态、内缩的目标与右对齐的计数，然后是交付建议、经验和路程。任务名左侧留出图标与强调线的间距。底部进度条标注“当前任务进度”。

跨区交通默认显示正在走的一段，点击行程标题展开后续分段。任务列表依次显示接下来、后续行程和顺路机会；只有待接任务时标为“顺路可接”。技能与副本建议在列表末尾，已选择副本时退出入口位于顶部。真实任务名与子目标使用公共字号，说明与状态用辅助字号。

主行程连续展示当前目标、接下来和后续任务；顺路机会单列其后，避免穿插打断主行程。任务名、地点、待接任务、真实子目标及完成数量、顺路与后续安排均保留。说明只写玩家当前需要做的事；完整条件放详情或悬停说明。接取、执行、交付使用一致图标；子目标再缩进一级。

任务列表、地图和中央导航共用透明底行动图标。目标姓名板沿用接取与目标图标，交付问号由游戏显示在 NPC 头顶。金色叹号表示接取，绿色问号表示可交付，灰色问号表示完成后交付，绿勾表示已完成。击杀用斜刃单剑，收集用紫色束口袋，交谈用气泡，物件互动用手，施法用闪电，声望用旗帜，前往地点用图钉，副本入口用拱门。任务类型不明时显示准星。进行中的标题取当前或首个未完成目标的图标，子目标各自显示行动。普通与 DaylightUI 皮肤保留图标的原色。

同一接交任务聚集地附近的可接任务集中列在顺路栏；下一级适合做的本地任务可先接，摘要标明“X级再做”，执行排序仍按原等级规则。附近明确未开通的飞行点使用同一列表和飞行图标，左键导航、右键可在本地图暂不提示，开通后自动移除。顺路行显示随移动更新的距离，复用现有刷新，不触发路线重算。

顺路待接任务整行左键导航到接取 NPC／物体，物品触发的任务显示使用入口；保留原任务优先选择，接取后恢复原行程。当前接取任务的右键菜单可“返回任务”；其他行的右键菜单保留查看详情及任务操作，Shift+左键仍插入任务链接。

同一任务的多个目标集中在当前任务下，“接下来”跳过已在上方显示的同任务目标；未接任务的目标尚未展示时，以“接取后”显示实际目标和目的地，副本目标标明副本名称，当前接取说明标明“先接备用”；若下一步是当前任务的交付，只显示“完成后交付 · NPC”，不重复任务名和目标。整批任务的物品需求合并到对应物品数量，不另列重复的“本次所需物品”。购买提示固定在该物品名下，使用辅助字号显示“可购买 · 商人”，地区等完整来源保留在悬停说明；物品数量始终在右侧同一列。

大地图用右上角的数字标出前 6 个行程地点。可接任务用金色叹号，击杀用蓝色单剑，收集用紫色袋子。绿色问号表示现在可交，灰色问号表示完成后交付。当前目的地有职业色外环，打开连线后只画玩家到这个地点的虚线。候选任务沿用规划筛选，同坐标合并，鼠标悬停查看任务、目标进度与地点。

小地图显示当前目的地和附近可操作的任务点，省去行程序号。只有当前目的地可以贴边，箭头随小地图方向旋转；进入视野后图标显示在实际位置。同一坐标有多项任务时，小地图优先显示当下可做的行动。左键临时导航。点击已接任务的未完成目标时，在大地图点亮客户端收录的任务范围；从小地图点击会打开目标所在的地图。关闭地图或右键返回原行程时结束这次高亮。

设置中的“地图与导航”集中控制地图协作：AILeveling 任务标记可选“全部候选任务／仅当前行程／关闭”，默认全部；大地图、小地图、目的地连线、危险怪标记、AILeveling 箭头与 WaypointUI 同步分别开关，保留原有选择。仅当前行程包含原路线预览和所选副本准备步骤；关闭任务标记不改变任务规划或导航选择。两列短说明交代与其他插件搭配的方法，设置立即生效并随已有配置保存。

主窗口左栏的“练级任务”和“职业任务”相邻。浏览只更新详情，点击“跟随这条职业任务线”才切换导航。详情标题只显示一次，主操作和任务链链接紧随详情，手动导航时显示恢复入口。任务、专业、职业、坐骑、区域和副本列表每行显示一行标题和一行摘要，悬停可读全文。搜索仅作用于当前分类。副本详情保持等级、任务数／经验、待接任务及可点击跑路指引。

副本建议直接复用已生成的副本候选：12 px 栏目显示可选数量，14 px 正文显示首选副本和任务数，前置数量放在悬停说明中，整行点击展开全部候选并打开对应详情；点击“安排整组任务”后切换行程。使用透明行和既有副本图标，不另开弹窗，不占用“接下来”或自动切换当前目标。菜单可选择本级稍后提醒，升级后恢复；移动期间保留已生成建议，刷新和选择沿用现有流程。

选择副本后，同一位置显示“副本行程 · 副本名”和可点击的“返回正常练级”；点击结束当前副本安排并恢复自动规划，保留已接任务和进度。标题栏右键菜单与副本详情使用相同取消文案，状态刷新期间也可取消；暂停引导和暂时隐藏副本建议不会隐藏此退出入口。

任务左键查看、右键操作；标题栏右键管理，鼠标悬停显示说明。被锁定／暂缓的任务保留既有状态。

装备建议只出现在任务列表滚动区内：背包建议使用一行 24 px 高的透明行，左侧小装备图标，中间品质色物品链接和绿色提升幅度，右侧 24 px 的 × 操作区。没有独立横条、背景或操作按钮排；右键菜单提供换装与忽略，点击 × 持久忽略该物品，标题菜单可以恢复提醒。任务奖励在当前任务下用一行显示；交付窗口的实际可选奖励优先，详细比较放悬停说明，屏幕中央的任务物品辅助区不再显示奖励建议。

附近有顺路且未完成的已接目标时，屏幕上方显示一条“顺便完成”。此提示条按 Polestar 的局部规格：宽 320 px，高度随两行文字计算，距屏幕顶部 150 px；平整深色底、1 px 细边框、内缩 1 px 的左侧 2 px 金线；16 px 行动图标距左 14 px，文字从左 44 px 开始，12 px 金色栏目标签距上 8 px，14 px 近白行动正文位于其下，间隔 4 px，底部留 8 px。文字用轻阴影，无粗描边；跟随全局背景透明度，尺寸和字号沿用已有缩放。正文按 Polestar 中文模板显示“具体行动，还差 N · 距离”，有物品来源时写“从来源收集物品”或“为物品击杀怪物”，距离按 5 码／米取整。左键临时指路，抵达后恢复任务导航；右键忽略当前位置附近的该目标，同一目标第二次忽略后在本次地图停留期间不再提示。完成目标、离开附近、暂停或隐藏 HUD 时收起；完整目标和交互说明放在提示条下方的悬停框。

## 6. 实施与检查

统一已有控件；DaylightUI 联动使用其公开接口，不增加主题引擎、皮肤切换或配置项。新增样式先选择已有颜色语义、字号和间距；确有新角色时再修改本规范。

复用现有 Lua 预览查看 HUD、主面板及地下城的普通／120% 字号，确认长名称、内缩目标、计数、链接和提醒不重叠。复用原有回归与构建，不为颜色、尺寸常量或每个页面新增测试场景。
