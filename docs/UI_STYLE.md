# AILeveling 界面规范

本文件是已有界面的统一规范。运行时颜色、字号和公共尺寸集中在 `UI/Main.lua`；各页面复用 `Text`、`Button`、`Rounded`。修改样式时先调整规范与公共值，再更新相关页面。

## 1. 整体风格

采用紧凑列表、深蓝黑底、柔和圆角、细分隔线和低强度原生材质。HUD、主面板、任务链、地下城、设置使用同一套色系。保留现有地心之战原生材质，降低纹理和金属边的亮度，使正文最突出。

HUD 背景透明度为 80%，正文保持清晰；主面板底色透明度为 96%，沿用用户已有整体透明度设置。列表行使用透明底，悬停才提亮；选中行使用浅色底和左侧金线，文字仍保留状态色。

## 2. 颜色语义

| 用途 | 颜色 | 规则 |
| --- | --- | --- |
| 正文、地点、页面标题 | 近白 `#F5F7FC` | 一级阅读信息 |
| 区域、说明、经验与路程标签 | 灰蓝 `#B3BACC` | 次要信息，保持可辨识 |
| 已接取、当前目标、主要操作 | 金色 `#E6BA66` | 与当前行动、装备提示共用 |
| 未接取、NPC、任务链接、跑路入口 | 浅蓝 `#94C9FF` | 同时配行动图标／文字 |
| 可交付、完成勾选、装备提升数值 | 绿色 `#6BD999` | 已接取任务不得使用此色 |
| 收集物品目标 | 紫色 `#C7ADFF` | 真实装备链接保留物品品质色 |
| 已完成正文、暂缓、不可用 | 灰蓝 | 完成项另有绿勾，受限项说明原因 |
| 错误或负向属性 | 浅红 `#F29C9C` | 仅用于实际错误、负值 |
| 导航箭头与距离 | 职业色 | 不覆盖任务状态色 |

状态同时使用图标和文字／进度，颜色不单独承担区分作用。背景、边线、悬停及选中颜色均从公共色表读取；页面不得再自设另一套色表。原生物品／技能链接的颜色保留。

## 3. 字号与对齐

| 层级 | 基础字号 | 使用位置 |
| --- | --- | --- |
| 标题 | 20 px | 当前地点、主页面标题、详情标题 |
| 品牌／导航 | 18 px | AILeveling 品牌、导航距离 |
| 任务名 | 15 px | 当前与后续任务、列表条目标题 |
| 正文 | 14 px | 子目标、任务说明、主要进度 |
| 辅助 | 12 px | 区域、状态、摘要、按钮、数值标签 |

沿用已有字号设置统一缩放，不额外增加局部字号选项。正文左对齐，数量与时间右对齐；计数按实际字宽分配，不保留无意义的空列。HUD 使用描边和轻阴影，主面板使用清晰的普通字形。

## 4. 间距与控件

- 使用 4 px 的间距基准：紧邻信息 4、行间 8、面板内边距 12、区段间距 16、子目标缩进 24 px。文字相关的间距跟随字号缩放。
- 主要图标 16 px，小图标 12 px；图标与文字留 8 px。原生勾选符号保留独立列。
- 面板圆角 6 px，按钮圆角 4 px；分隔线 1 px。列表不逐项叠加重边框和大卡片。
- 普通按钮高 28 px；图标操作区至少 24 px，使用中性悬停底。相邻按钮间隔 8 px。
- 地点和区域同排：地点在左，区域以辅助字在右，两者至少间隔 12 px。长名称按可用宽度换行。
- 只在实际滚动内容中预留 16 px 原生滚动条空间；其他区域使用完整内容宽度。
- 保留 HUD 鼠标调整宽高和小地图对齐。高度由文字决定，长内容放在已有滚动区；不靠隐藏任务信息缩小面板。

图标视距修正、原生控件锚点及 Polestar 装备横条允许保留必要的局部尺寸，不为对齐改写其行为。

## 5. 信息结构与交互

HUD 固定顺序为：行程标题 → 装备／职业提醒（有内容时）→ 地点和区域 → 当前行动及内缩子目标 → 交付建议、经验／路程 → 交通行程（有需要时）→ 顺路任务 → 接下来 → 后续行程 → 进度。

任务名、地点、待接任务、真实子目标及完成数量、顺路与后续安排均保留。说明只写玩家当前需要做的事；完整条件放详情或悬停说明。接取、执行、交付使用一致图标；子目标再缩进一级。

主界面保留“分类导航 → 列表 → 详情”的结构。任务、专业、职业、坐骑、区域和副本列表共用行样式。副本详情保持等级、任务数／经验、待接任务及可点击跑路指引。

任务左键查看、右键操作；标题栏右键管理，鼠标悬停显示说明。被锁定／暂缓的任务保留既有状态。装备横条保留 Polestar 的金色提示、品质色物品链接、提升数值、“装备它／忽略这件／关闭”行为。

## 6. 实施与检查

统一已有控件，不增加主题引擎、皮肤切换、配置项或新功能。新增样式先选择已有颜色语义、字号和间距；确有新角色时再修改本规范。

复用现有 Lua 预览查看 HUD、主面板及地下城的普通／120% 字号，确认长名称、内缩目标、计数、链接和提醒不重叠。复用原有回归与构建，不为颜色、尺寸常量或每个页面新增测试场景。
