# RestedXP 功能对照与自动规划验收

2026-11-09 最新修正：用户明确反对手写指南和导入功能。AiLeveling 根据角色实时状态自动生成行程，借鉴 RestedXP 的导航、交互与练级辅助体验。原 RX01／RX02 的自定义指南及脚本指令实现要求改为自动规划与接续验收，删除导入、解析、标签跳转和固定指南内容待办。原 PLAN.md 完整交付条件继续保留；独立装备获取与再刷扩展仍暂缓，保存在 git stash。

目标客户端为 Forever 1.60.1.70862。功能对照包括 RestedXP Guide 和此前指定的 RestedXP Waypoints。以下按用户可见功能归类；各版本专属功能需要核对适用条件，未核对项目仍待审计。清单不是完成证明，不能用其中一个功能的测试替代整体验收。
