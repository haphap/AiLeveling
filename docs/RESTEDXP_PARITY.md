## 固定对照来源

- [RestedXP Guide 官方介绍](https://www.curseforge.com/wow/addons/restedxp-guide)：路线、自动接交、目标宏、箭头、界面、练级计时及自定义指南。
- [RestedXP Waypoints](https://www.curseforge.com/wow/addons/restedxp-waypoints)：RXP／Waypoint UI 同步、动作图标、动态更新及手动航点恢复。
- [官方公开仓库](https://github.com/RestedXP/RXPGuides/tree/d583b89e455d73be6b93970579f074ecf6bb6326)：固定提交 `d583b89e455d73be6b93970579f074ecf6bb6326`，SettingsPanel.lua SHA256 `f6a35a1c3fb9eefd4aabd757dc331d6a03191b18d2371bc9839021f242e7037a`。设置标签用于盘点行为，独立实现运行时；危险位置与急救参考表按原许可单独收录，见 `DANGER_DATA_AUDIT.json`，未导入指南内容。

- 背包功能依据：[InventoryManager.lua](https://github.com/RestedXP/RXPGuides/blob/d583b89e455d73be6b93970579f074ecf6bb6326/InventoryManager.lua) 的商店出售、垃圾标记、最低价值物品丢弃与灵魂碎片数量设置；独立接入现有 Merchant 和原生背包接口，未复制其背包框架。
- 原生接口依据：固定 Forever UI 的 GossipInfoDocumentation.lua、GossipFrameShared.lua 和 QuestFrame.lua。任务接交需由实际客户端事件确认。

## 已核对的适用边界

固定源码 `SettingsPanel.lua:22—30,1720—1735` 将附近显示依赖的主动扫描关闭于 2025 年及之后构建；`RXPGuides.lua:204—207` 将 Interface 16001 归为 FOREVER；`SettingsPanel.lua:1260—1271,1320—1398` 分别说明自给自足行为，并限制内容阶段／硬核为 CLASSIC、多开为 RETAIL。以上据实际行为收口，不增加替代模式。天赋虽使用不同原生界面，上游 TOC 明确加载 camelot，继续按适用功能处理。

RX17 依据固定 `SettingsPanel.lua:1320—1335,1498—1524,2471—2486`、`functions.lua:7672—7705` 与 `CptStadicsVendorTreasures.lua:9` 确认：专业菜单来自指南解析，宝藏追踪与商人宝藏分别受接口号和语言限制。现有 `Data/Questie.lua` 读取专业要求，`State.lua` 读取角色技能，`Planner/Eligibility.lua` 依据实际等级筛选任务，继续沿用。

Waypoint 联动直接使用 [Waypoint UI 公开 API](https://github.com/Adaptvx/Waypoint-UI/blob/9d05f078af5ebd53c9d14c6d7eca627e0ea055ba/API.lua)，坐标输入／输出及手动点归属核对同提交 `Code/MapPin/MapPin.lua`，图标类型核对 `Code/Waypoint/Waypoint_DataProvider.lua`；使用游戏图集，不导入桥接插件的代码、素材或设置体系。

## 关闭差距的规则

完成条件由 PLAN.md 的批次规定。本表只把已确认差距更新为对应实现与操作结果；完成后仅因用户新要求或真实缺陷重开。

适用性不能以“尚未实现”为依据排除，也不能把未经核对的设想自动列为必做。无需给每一行同时新增数据工程、独立回放和测试文件；复用覆盖同一完整流程的验证。日志数量和测试数量不代表功能完成。
