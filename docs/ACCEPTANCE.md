## 一次贯通的验收流程

| 流程 | 通过条件 |
| --- | --- |
| 干净安装／升级 → 登录／重载 → 恢复 | 依赖就绪；窗口和中文可读；配置迁移保留，角色任务状态与原生日志一致；无 Lua 错误 |
| 接取 → 共享目标 → 集中交付 → 后续 | 已接、未接、可交付明确；多个任务同时可见；就近交或一起交的建议与顺序一致；已交任务撤下，其他任务继续；低价值任务可手动处理 |
| 步行／飞行／船只／炉石 → 到达 → 继续 | 地图、箭头和主卡一致；手动航点和暂停可恢复；服务可忽略；到达位置不误判任务完成 |
| 任务物品／目标按钮 → 战斗 → 脱战 | 数量和用途正确；点击、快捷键、高亮可用；战斗期间无受保护错误，脱战后同步最新目标 |
| 副本准备／等队 → 进入／目标 → 离开／交付 → 下一步 | 前置、实际实例和原生准入状态一致；交齐后离本再恢复自动任务；取消或中断不计作完整活动样本 |
| 辅助功能 → 配置／角色切换 → 插件共存 | 天赋预览与原生确认、背包操作、队伍进度、统计、危险／稀有提示符合功能对照；Waypoint UI、DaylightUI、Lueur 共存；实际帧耗时和内存无持续异常 |

共用流程一次贯通，独有起始区、职业和跨区分歧沿现有覆盖清单确认。发现缺陷只补对应修复与回归，再复验受影响流程。
