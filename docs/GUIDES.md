# 自定义指南

源码中的 `/ail guides` 或设置页“选择／导入指南”打开管理窗口。粘贴文字后点击导入，再选择使用；同账号共享指南，角色分别保存进度。可导出文字、重置当前角色进度、暂缓当前步骤、删除指南或恢复自动规划。恢复界面设置会保留已导入指南。

当前实现基础步骤运行。完整 RestedXP 指令、压缩导入串、商业指南包、坐标指令、标签跳转、动态条件分支和全程路线仍在 RESTEDXP_PARITY.md 中待实现。现阶段输入为以下明确支持的纯文本格式；未知指令或参数整份拒绝并指出行号，不执行 Lua。

| 写法 | 含义 |
| --- | --- |
| `#name 标题` | 必填；与分组共同确定指南身份 |
| `#group 分组` | 可选，默认“自定义指南” |
| `#next 标题` | 完成后显示下一份指南名称，当前由玩家在窗口选择 |
| `step` | 新步骤；同一步所有要求满足后继续 |
| `step << Alliance Human Warrior` | 角色条件；空格表示同时满足，`/`表示任一分支，`!`表示排除 |
| `>> 说明` | 当前步骤说明；只有说明的步骤由玩家暂缓后继续 |
| `.accept 783` | 等待实际接取任务；已完成的非重复任务可跳过 |
| `.complete 7,1` | 等待日志中该任务第一个目标完成；省略目标序号时等待任务可交付 |
| `.turnin 783` | 等待实际交付事件或非重复任务完成事实 |
| `.collect 8932,20` | 等待实际携带数量达到20 |
| `.xp 12` | 等待实际达到12级 |
| `-- 注释` | 整行注释 |

条件支持 Alliance／Horde、九职业英文名、Human／Orc／Dwarf／NightElf／Scourge（或Undead）／Tauren／Gnome／Troll，以及整数等级门槛。尚不识别的种族或复合表达式会报错。条件在步骤到达时判断；需要先升级的步骤应使用`.xp`。

示例：

```text
#name 北郡接交示例
#group 我的指南
step
.accept 783
step
.turnin 783
step
>> 完成后选择下一份指南，或恢复自动规划。
```

目的地、任务资格和前置沿用当前数据库与任务日志。未接任务先引导接取，放弃后重新接取；指定目标没有对应日志要求时保留该步骤并提示处理。坐标到达不完成任务；重复任务从选用或重置指南时的交付次数开始计算。更新同名指南会使各角色在下次使用时重新计算步骤，未变化的重新导入保留进度。

手动任务锁定、手动航点、当前副本和必要服务保留优先权。同NPC任务仍先完成整组再交；指南进度等待真实交付。自动接交仍受原有开关、Shift和战斗条件控制，只处理当前指南引导的任务。普通任务列表继续保留全部已接任务。

限制为每账号16份、每份64KB和1000步。导入失败保留原指南。删除指南不改游戏任务或完成事实，删除需要在窗口再次点击确认。重置进度仍会读取真实已完成任务并自动接续。
